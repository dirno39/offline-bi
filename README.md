# Offline BI

인터넷 연결 없이 브라우저만으로 동작하는 Tableau 스타일 셀프서비스 BI 도구입니다.
회사 내부망(폐쇄망) PC에 폴더째 복사한 뒤 `index.html`을 더블클릭하면 바로 실행됩니다.
서버, 설치, 외부 CDN이 필요 없고 데이터는 PC 밖으로 전송되지 않습니다.

## 실행 방법

1. `offline-bi` 폴더 전체를 사내 PC나 공유 드라이브에 복사합니다.
2. `index.html`을 Chrome 또는 Edge(Chromium)로 엽니다.
3. 엑셀/CSV 파일을 창에 끌어다 놓거나 **데이터 추가**를 누릅니다. 처음이라면 **샘플 데이터로 시작**을 눌러 보세요.

> 사내 웹서버(IIS, Nginx 등)에 정적 파일로 올려 여러 사람이 접속해도 됩니다. 빌드 과정은 없습니다.

## 주요 기능

| 영역 | 기능 |
|---|---|
| 데이터 | CSV · TSV · TXT · XLSX · XLS · XLSM · ODS · JSON, 여러 시트 선택, UTF-8/EUC-KR(CP949) 자동 인식, `1,234` · `12%` · `₩` · `2024.01.05` · `2024년 1월 5일` 형식 인식, 앞자리 0 코드값 보존 |
| 데이터 원본 | 필드 유형/역할 변경, 이름 변경, 미리보기, 데이터 교체(시트 유지), 유니온(행 추가), 조인(Inner/Left/Full) |
| 시트 | 열/행 선반, 마크 카드(색상·크기·레이블·세부정보·툴팁)로 드래그 앤 드롭, 필드 더블클릭 자동 배치, 필을 선반 밖으로 끌면 제거, Ctrl+드래그로 복사 |
| 정렬 | 툴바 오름차순/내림차순 원클릭 정렬(측정값 기준, 다시 누르면 해제), 표 머리글 클릭 정렬(차원=이름순, 측정값=값 기준) |
| 필(pill) 메뉴 | 집계(합계·평균·중앙값·개수·고유 개수·최소·최대·표준편차·분산), 날짜 단위(연/분기/월/주/일, 불연속 분기·월·요일), 정렬(값/측정값 기준), 빠른 테이블 계산(누계·구성비·차이·증감률·순위·이동평균), 숫자 형식 |
| 차트 (32종) | 자동, 텍스트 테이블, 하이라이트 테이블, 히트맵, 세로/가로 막대, 묶은 막대, 누적 막대, 100% 누적, 라인, 영역, 누적 영역, 콤보(막대+라인), 이중 축 라인, 파이, 도넛, 트리맵, 선버스트, 산점도(추세선), 버블, 히스토그램, 상자 수염, 폭포, 퍼널, 파레토, 불릿, 레이더, 게이지, KPI 카드, 생키, 달력 히트맵 |
| 필터 | 목록(검색·제외), 범위, 기간(최근 7/30/90일·YTD·작년 등), 상위/하위 N, 모든 시트에 적용, 필터 카드(빠른 필터), 마크 클릭 → 이 항목만 유지/제외 |
| 계산된 필드 | `[필드]` 참조, `IF/ELSEIF/ELSE/END`, `CASE WHEN`, `IIF`, 문자열·숫자·날짜 함수 50여 종, 실시간 검증과 미리보기 |
| 대시보드 | 시트를 캔버스에 끌어 배치, 이동/크기 조절, 자동 배치, 텍스트 개체, 필터 카드, **필터로 사용**(시트 간 동작 필터) |
| 서식 | 글자 크기(작게/보통/크게/아주 크게, 차트·표·KPI·제목 공통), 범례 위치(위/오른쪽/아래), 숫자 형식(만/억 단위, ₩, %, K/M), 색상 팔레트, 연속 색상, 레이블, 범례, 총계, 참조선 |
| 저장/내보내기 | 브라우저 자동 저장(IndexedDB), 통합 문서 파일(`.obi`, 데이터 포함), PNG 이미지, 요약/전체 데이터 CSV·Excel, 인쇄/PDF |

단축키: `Ctrl+Z` 실행 취소 · `Ctrl+Y` 다시 실행 · `Ctrl+S` 통합 문서 저장 · `Ctrl+O` 열기

## 폴더 구조

```
offline-bi/
├── index.html          진입점
├── css/app.css
├── js/
│   ├── util.js         공통 유틸(포맷, 모달, 메뉴, 색상)
│   ├── data.js         파일 파싱, 타입 추론, 유니온/조인, 샘플 데이터
│   ├── calc.js         계산된 필드 수식 엔진 (eval 미사용)
│   ├── query.js        필터, 그룹화, 집계, 정렬, 테이블 계산
│   ├── charts.js       차트 종류와 ECharts 옵션 생성
│   ├── app.js          상태, 실행 취소, 저장, 탭, 내보내기
│   ├── ui-sheet.js     워크시트 화면, 드래그 앤 드롭, 필터/계산 대화상자
│   ├── ui-dash.js      대시보드
│   └── ui-ds.js        데이터 원본 화면
├── fonts/              Pretendard Variable (SIL OFL 1.1, 로컬 번들)
└── lib/                로컬 번들 라이브러리
    ├── echarts.min.js     Apache ECharts 5.5.1 (Apache-2.0)
    └── xlsx.full.min.js   SheetJS CE 0.18.5 (Apache-2.0)
```

## 참고 및 제한 사항

- 모든 처리는 브라우저 메모리에서 이루어집니다. 수십만 행까지는 원활하며, 그 이상은 PC 사양에 따라 느려질 수 있습니다.
- 자동 저장은 브라우저별·PC별로 저장됩니다. 다른 사람과 공유하려면 `.obi` 파일로 저장하세요.
- 지도 차트는 오프라인 지도 데이터가 필요해 포함하지 않았습니다.
- 권장 브라우저: Chrome, Edge 최신 버전. (Internet Explorer 미지원)
