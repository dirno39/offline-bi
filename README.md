# Offline BI

인터넷 연결 없이 브라우저만으로 동작하는 Tableau 스타일 셀프서비스 BI 도구입니다.
회사 내부망(폐쇄망) PC에 폴더째 복사한 뒤 `index.html`을 더블클릭하면 바로 실행됩니다.
서버, 설치, 외부 CDN이 필요 없고 데이터는 PC 밖으로 전송되지 않습니다.

## 실행 방법

1. `offline-bi` 폴더 전체를 사내 PC나 공유 드라이브에 복사합니다.
2. `index.html`을 Chrome 또는 Edge(Chromium)로 엽니다.
3. 엑셀/CSV 파일을 창에 끌어다 놓거나 **데이터 추가**를 누릅니다. 처음이라면 **샘플 데이터로 시작**을 눌러 보세요.

> 사내 웹서버(IIS, Nginx 등)에 정적 파일로 올려 여러 사람이 접속해도 됩니다. 빌드 과정은 없습니다.

## 참고 및 제한 사항

- 모든 처리는 브라우저 메모리에서 이루어집니다. 수십만 행까지는 원활하며, 그 이상은 PC 사양에 따라 느려질 수 있습니다.
- 자동 저장은 브라우저별·PC별로 저장됩니다. 다른 사람과 공유하려면 `.obi` 파일로 저장하세요.
- 지도 차트는 오프라인 지도 데이터가 필요해 포함하지 않았습니다.
- 권장 브라우저: Chrome, Edge 최신 버전. (Internet Explorer 미지원)

## 데이터 정리 (Prep) 사용 예

KOSIS 같은 통계표는 보통 `연도` 아래에 `총인구 · 남 · 여 …` 가 가로로 펼쳐진 두 줄 머리글 구조라 그대로는 필터나 차트에 쓰기 어렵습니다.

1. 파일을 불러오면 여러 줄 머리글을 자동으로 합치고 **데이터 정리** 화면이 열립니다.
2. **추천 변환 적용**을 누르면 숫자 열들이 행으로 내려가 `시도 | 연도 | 항목 | 값` 형태가 되고, `-`·`x` 같은 통계 기호는 Null로, 값은 숫자로 바뀝니다. 피벗 해제는 "선택하지 않은 열 외 전부" 규칙으로 저장돼 다음 달 파일의 새 시점 열도 함께 내려갑니다.
3. 필요에 따라 `전국` 같은 합계 행은 **행 필터**로 제외하고, `총인구 (명)` 의 단위는 **값 정리 → 괄호 안 내용 제거**, `한국인_남` 은 **열 분할**(`_`)로 `구분 | 세부` 로 나눕니다.
4. **적용**을 누르면 데이터 원본이 바뀝니다(`Ctrl+Z`로 되돌릴 수 있어요). 다음 달 파일은 데이터 원본 화면의 **데이터 교체**로 넣으면 같은 단계가 자동으로 다시 적용되고, 열 구성이 달라졌으면 경고로 알려 줍니다.

데이터 원본 화면의 **데이터 정리…** 버튼으로 언제든 흐름을 열어 단계를 보고, 끄고, 순서를 바꾸고, 지울 수 있습니다.
